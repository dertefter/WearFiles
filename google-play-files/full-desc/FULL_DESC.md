A simple open-source file manager. Designed for Wear OS ⌚

Features:
📱 Transfer files from phone to watch
🖼️ View images (JPG, PNG, etc.)
📄 Open PDF files
📂 Browse files on the device
🗑️ Delete files
📋 Cut / Copy / Paste
📌 Pin files and folders to the home screen

Source code is available on GitHub:
https://github.com/dertefter/WearFiles
